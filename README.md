## Overview About Project :

CoreLink is a minimum viable product for an Entrepris Resource Planning platform that I created

## Features :

 - ability to add Managers
 - ability to add Clients
 - ability to add products
 - check the payement history
 - Check the reports and orders
 - Check analytics using graphical interfaces
 - unified Portal for Owner and Managers
 - specific UI for Clients


## Tech Stack

 - Front-end :
   
   - Next.js
   - Typescript
   - NextAuth.js
   - Supabase
   - Redux
   - Shadcn UI

 - Backend :

     - Node.js
     - Express.js
     - PostgreSQL
