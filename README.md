
## Overview About Project : 

CoreLink is a minimum viable product for an Entrepris Resources Planning platform designed to serve two roles (owner & manager)

## Features : 

- different actions based on role type 
- ability to add/edit/remove (managers/clients/orders)
- Graphical interfaces shows analytics about the work flow

## Tech Stack :

 - Frontend : 
   
   - Typescript
   - Next.js
   - NextAuth.js
   - supabase
   - Shadcn UI

 - Backend :

   - Node.js
   - Express.js
   - Typescript
   - Relational Database (PostgreSQL)
